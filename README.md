# 北森学习系统 · 交互复刻原型

依据北森学习系统官网、公开产品截图及官方演示视频制作的浏览器交互原型。范围已从 AI 陪练扩展到整个学习平台。非北森官方服务。

## GitHub Pages 公网发布

将本目录内容推送到目标仓库默认分支后，在仓库 Settings → Pages → Build and deployment 中选择 GitHub Actions。工作流会发布 dist 目录；后续推送默认分支会自动更新。可在 Actions 页面查看发布状态及最终网址。

GitHub Pages 公开网页包含演示代码和演示数据。每位访问者的学习记录仅保存在自己的浏览器，不上传到 GitHub。本站不是北森官方服务。

## 使用

在本目录执行 `node serve.cjs`，然后打开终端显示的 `http://127.0.0.1:4317`。也可将 `dist` 托管到静态 HTTP 服务。无需安装依赖或构建。

右上角切换「学员端」「团队经理」「管理员端」。数据只保存在当前浏览器：刷新保留，不同浏览器不共享。管理员 → 门户与激励可切换门户、切换现代白灰与旧版蓝色侧栏、导出全部演示数据。

## 建议体验路径

1. 学员端 → 学习计划 → 新员工入职培训：完成课程、记录笔记、提交作业、通过综合考试，再查看完成规则领取演示证书。
2. 报名中心：报名活动、演示签到、记录请假。
3. 管理员端 → 课程管理：新增图文课程、发布，然后切换学员端查看。
4. AI 内容与训练：体验做课草稿、课程推荐、文字陪练与评分、领导力对话、模板出题。
5. 师资认证：配置活动信息、报名/试讲/审批/证书流程和通知配置。
6. 学习报表：查看当前浏览器产生的学习与考试结果，并导出记录。

## 覆盖范围

课程与笔记、培养计划、作业、结业证书、培训报名签到、培训日历、考试与题库、师资认证、培训需求、年度计划、外派培训、问卷、知识资源、岗位地图、IDP、PIP、导师带教、循环认证、学习圈、积分与勋章、报表、组织分组、门户与业务规则。

详细说明见 [功能覆盖与依据](FEATURES.md)。应用右上角「查看功能覆盖」提供相同的模块边界和来源，并支持导出 CSV。

## 实现与限制

- 静态 HTML/CSS/JavaScript；无框架依赖；课程正文和人物均为演示内容。
- 已实现的学习、考试、签到、兑换和管理记录通过 localStorage 保存。
- AI 为本地规则或模板模拟，不包含大模型、语音识别、数字人或真实智能评分。
- 需求审批、IDP/PIP、外派、循环认证和业务规则以可编辑记录及状态推进演示，不执行真实审批、定时任务或通知。
- 没有真实登录、服务端权限、多人同步、视频上传转码、SCORM、直播、企业微信/钉钉、HR 或 PaaS 集成。
- 官方旧视频中的数据为 2020 年，当前官网截图与旧视频存在版本差异。本原型参考其公开布局和流程，不能保证商业系统全部功能或当前 UI 逐页一致。

## 文件

- `dist/index.html`：入口。
- `dist/portal.js`：页面和交互逻辑。
- `dist/portal-data.js`：演示数据、通用业务模块配置。
- `dist/portal.css`：学习系统样式；复用 `styles.css` 的基础控件。
- `dist/coach/`：内嵌陪练模块。
- `serve.cjs`：本地静态服务器。
- `QA.md`：验证结果。

本项目由公开网页/视频的可观察证据指导重建，未获取北森内部源码、接口或登录后资源。REA 已安装配置，本次没有可供分析的商业系统运行包，因此没有进行反编译或内部 API 还原。
